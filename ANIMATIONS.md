# Animation & motion summary

Every animation has a `prefers-reduced-motion` branch. Under reduced motion: no 3D
scenes (static gradient instead), no parallax, no tilt, no stagger, no smooth scroll,
no custom cursor, no preloader, and simple fades only. All DOM motion animates
`transform` and `opacity` only. Nothing flashes.

## Bundle overview (gzip, production build)

- Initial JS: ~171KB (React, GSAP + ScrollTrigger, Framer Motion, Lenis, React Hook Form, Zod)
- Lazy: hero 3D (three + R3F + Drei) ~245KB total, Lottie player ~52KB, Lottie JSON 2–5KB each
- CSS: ~6KB
